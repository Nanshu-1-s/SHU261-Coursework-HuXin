## 复现方式

需要 Node.js 环境。

```bash
cd diagrams
npm install
node build.mjs
```

`build.mjs` 会扫描 `diagrams/` 下所有 `.svg` 文件，用 `@resvg/resvg-js` 渲染成 PNG 写入 `../images/`，文件名保持一致。中文字体使用系统字体，Windows 下默认取微软雅黑，其他平台需要在 `build.mjs` 的 `defaultFontFamily` 里改成系统已有的中文字体。

## 视觉规范

四张图共用一套配色，颜色承担信息而不是装饰。

| 颜色 | 含义 |
|---|---|
| 琥珀 #b45309 | 语音类资产 |
| 青绿 #0f766e | 音乐类资产 |
| 玫红 #9f1239 | 音效类资产与风险提示 |
| 蓝 #1e40af | 画面与声音一体，或与画面相关的规则 |
| 橄榄 #4d7c0f | 已有画面生成的声音轨 |

字号上标题 30px、小节标题 15 至 17px、正文说明 12 至 14px，正文说明不小于 12px 以保证在 GitHub 上缩放后仍可读。
